# 잔월의 서약 · THE LAST BELL — v1.5

다섯 장에 걸쳐 잃어버린 달과 종의 수수께끼를 찾아가는 **오리지널 중세 픽셀 판타지 액션 RPG**입니다.

## 이번 버전

- **5장, 90여 개 장면**: 각 장의 인물, 사건, 전투와 결정, 지역별 보스
- **후반 난이도 증가**: 장에 따라 몬스터 체력/공격력/추격속도/공격 주기가 점진적으로 상승
- **전투 조작 유지**: 자동 길 이동, 전투에서 왼쪽 이동 스틱 + 검격 + 마법 + 달걸음 회피
- **전투 UI 리디자인**: 상태창과 액션 버튼, 적의 체력 표시, 작은 공격 예고 마커
- **화면의 붉은 범위 원 및 점선 길 표시 제거**
- **장거리 이동 축약**: 먼 목적지는 장면 전환 후 짧은 길만 걸어갑니다.
- **은화 상점**: 검 +7 / 갑옷 체력 +25 강화, 휴식, 망토·장식·인장 커스터마이즈
- **장비 외형 변화**: 영웅 픽셀 스프라이트에 점진적으로 외관이 반영되고 세이브됩니다.
- **기존 세이브**: v1.4 기존 장면 번호를 제목으로 찾아 새 확장 서사에 대응합니다.

## 플레이

`index.html`을 브라우저에서 실행합니다. GitHub Pages 지원.

- 이야기 구간: 자동으로 이동하고 등장인물과 대화합니다.
- 전투 구간: 왼손으로 이동 스틱 조작, 오른손으로 공격·회피·마법을 사용합니다.
- 상점: 상단 `✥` 버튼으로 열거나 장 사이에 등장하는 장인의 가게에서 이용할 수 있습니다.
- 쉬운 조작을 유지하면서도 후반부는 회피와 강화 선택에 따라 난도가 달라집니다.

## 개발 파일

`game.js` 메인 엔진 / `visuals.js` 월드 및 장비 외관 / `chronicles.js` 기본 서사 / `expand_chapters.js` 장편 확장 / `style.css` UI / `audio/` BGM / `preview/` 미리보기

이 게임은 장기 확장을 위한 기반이므로 이후에도 분기 선택의 실제 후속 결과, 보스별 전용 애니메이션, 더 큰 세계와 아이템 시스템을 계속 발전시킬 수 있습니다.
