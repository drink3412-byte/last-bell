# 잔월의 서약 — THE LAST BELL

> 달이 부서진 밤, 마지막 종은 울리지 않았다.

**오리지널 판타지 도트 RPG** · 모바일 / PC · HTML + CSS + JavaScript

## v1.3 — 길의 끝에서 시작되는 서사

- **시점 유지**: v1에서 시작한 캐릭터 중심의 가까운 시점을 유지하고 자동 길찾기의 회전과 속도를 다듬었습니다. 즉시 방향 전환을 줄이고 가속·감속, 발걸음, 망토 움직임, 카메라 따라오기를 부드럽게 했습니다.
- **간편한 수동 전투**: 이동은 자동으로 진행하되 전투는 `검격`과 `마법`을 직접 눌러 진행합니다. 세 번 연속 누르면 공명 공격이 발생하고, 버튼과 화면을 복잡하게 채우지 않습니다.
- **마법 해금**: 레벨 1 / 3 / 5 / 8 / 12 / 16에 달빛 파동, 서리별, 은빛 수호, 유성 성가, 새벽의 서약, 달의 시계를 순서대로 배웁니다. `✦ 마법 선택` 버튼으로 기술을 전환합니다.
- **단계별 장비 외형 변화**: 대장간에서 검과 갑옷을 강화하면 한 번에 완전히 바뀌는 대신 검 문양·반짝임·금속 장식이 단계적으로 늘어납니다.
- **오리지널 판타지 BGM**: 연주 악기 음색(현악, 하프, 목관, 합창)을 겹친 독창적인 「The Bells Beyond the Vale」를 게임에 포함했습니다. SFX와 별도로 재생되며 일시정지에서 끌 수 있습니다. 처음 시작할 때 소리를 허용해야 재생됩니다.
- **세계를 확장하는 연대기**: 제1장 11개 장면 뒤로 총 34개 장면을 추가하여 총 45개 장면을 플레이할 수 있습니다. 하얀 회랑·물비늘 해안·가면의 왕국·달의 안쪽 등을 새로 배치했습니다. 서약 선택은 저장되며 능력치에 반영됩니다.
- **시각효과 유지**: 기존 날씨, 조명, 반짝이는 입자 효과를 유지하면서 지역별 기둥·파도·성벽·제단을 추가했습니다.

## 조작

| 기능 | 방법 |
|---|---|
| 장면 사이 이동 | 자동 · 화면 아래 길잡이 |
| 검격 / 3연격 | 우측 아래 `⚔ 검격` 버튼 / PC `Space` |
| 마법 사용 | 우측 아래 마법 버튼 / PC `Q` |
| 배운 마법 변경 | `✦ 마법 선택` / PC `Tab` |
| 레벨업 능력 선택 | 성장 화면에서 원하는 축복 터치 |
| 게임 내 일지 / 설정 | 화면 우측 위 메뉴 |

## 구성

- `index.html` — 실행 화면과 조작 UI
- `game.js` — 월드 이동, 렌더러, 전투 및 성장 시스템
- `chronicles.js` — 이야기 장면(텍스트/전투/서약) 데이터
- `style.css` — UI와 모바일 배치
- `audio/the-bells-beyond-the-vale.ogg` — 오리지널 BGM
- `title-art.svg` — 메인 화면 아트
- `preview/forest.webp` — 게임 프리뷰

## 개발 상태

이 버전은 장편 스토리와 전투 기술의 **첫 확장 단계**입니다. 100배 분량의 완성 게임을 의미하지 않습니다. 이후 에피소드, 선택의 결과, 스킬 성장 트리, 장비 꾸미기, 지역 서브퀘스트를 확장할 수 있도록 이야기 데이터를 분리했습니다.

브라우저의 저장 공간에 자동 저장됩니다. GitHub Pages에서 정적 웹게임으로 플레이할 수 있습니다.

## v1.4 — The Silver Interval / 달빛의 간극

### 진짜로 움직이는 전투
- 장면 사이 여행은 계속 자동으로 진행됩니다.
- 전투 중에는 **왼쪽 원형 스틱을 드래그**해 자유롭게 움직입니다. 스틱 밖 왼쪽 화면에서도 드래그로 이동할 수 있습니다. PC는 WASD/방향키입니다.
- **검격**, **마법**, **달걸음 회피** 세 버튼으로 싸웁니다. PC에서는 Space / Q / Shift(또는 F)입니다.
- 몬스터가 공격하기 전에 붉은 공격 예고가 표시됩니다. 회피에는 잠깐의 무적 시간과 재사용 대기시간이 있습니다.
- 공격 예고 중 타이밍에 맞춰 회피하면 **월광 공명**을 획득하고 MP를 조금 회복합니다. 공명 3개는 검의 3타를 강화하고, 마법 사용 시에는 누적 공명에 따라 마력 소모가 감소합니다.
- 전투는 일정 지역 안에서 진행되며 전투가 끝나면 자동 이동이 다시 시작됩니다.

### 소리·그림 개선
- 스토리 진행 대사를 넘길 때 나오는 큰 종소리를 아주 짧은 저음의 페이지 넘김 소리로 교체했습니다. 일반 효과음도 전체적으로 조절했습니다.
- `visuals.js`의 새로운 픽셀 아트 레이어에 수백 송이 꽃, 숲의 발광 나무, 석조 아치, 첨탑, 달빛 수정, 문양 모자이크, 도금된 가옥과 강화된 기사 스프라이트가 들어갑니다.
- 도트 아트는 월드 맵에 한 번만 그려놓고, 동적으로 변화하는 소량의 효과만 프레임마다 갱신합니다. 기존 날씨, 촛불, 파티클은 유지했습니다.
- 브라우저 캐시 갱신: `?v=14` (게임 페이지), CSS/JS 리소스는 고유 버전 문자열 사용.
