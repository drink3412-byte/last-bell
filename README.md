# 잔월의 서약 · THE LAST BELL

> 달이 부서진 밤, 마지막 종은 울리지 않았다.

**중세 픽셀 판타지 액션 RPG · 한국어 · 모바일/PC · 무료 오프라인 실행**

잿빛 마을 엘든에서 여정을 시작해 숲과 고대 유적을 탐험하고, 달 조각을 모아 성당의 비밀을 밝히는 브라우저 게임입니다. 게임의 그래픽과 효과음은 코드로 직접 생성되며 외부 라이브러리나 에셋 다운로드가 필요하지 않습니다.

## 조작

| 동작 | 갤럭시탭/모바일 | PC |
|---|---|---|
| 이동 | 지도 터치, 길게 누르기 | WASD / 방향키, 마우스 |
| 일반 공격 | 몬스터에 접근하면 자동 공격 | 동일 |
| 달빛 파동 | 우측 하단 스킬 버튼 | Space |
| 대화 | NPC를 터치 | NPC 클릭 또는 E |
| 지도 / 여정 일지 | 화면 상단 버튼 | M / I |

게임 진행은 지원되는 브라우저의 로컬 저장소에 저장됩니다. 다른 기기 사이에서 세이브가 자동 동기화되지는 않습니다.

## 게임 실행 및 웹 공개

- 저장소: https://github.com/drink3412-byte/last-bell
- 실행 파일: `index.html` (별도 빌드 과정 불필요)
- GitHub Pages 공개: 저장소의 **Settings → Pages → Deploy from a branch → main / (root)** 선택 후 Save
- 공개 후 예상 주소: https://drink3412-byte.github.io/last-bell/

## 코드 구조

```
index.html     # 게임 화면과 대화창, 버튼 구조
style.css      # 반응형 화면과 UI 스타일
game.js        # 게임 월드, 렌더링, 자동 전투, NPC, 퀘스트, 저장
.nojekyll      # Pages에서 Jekyll 처리를 비활성화
```

## 수정과 버전 관리

새 기능을 추가할 때 기능별로 커밋을 나누면 되돌리기 편합니다. 예: `feat: add new village` / `fix: improve touch movement`. 이 저장소의 소스는 한 곳에서 지속적으로 수정하는 용도로 구성했습니다.

## 이용 관련

개인 프로젝트 소스의 공개와 별개로, 타인에게 재사용·재배포 권한을 명확히 부여하려면 별도의 라이선스 파일을 추가해야 합니다. 현재 별도의 오픈소스 라이선스는 지정하지 않았습니다.
