# 잔월의 서약 · THE LAST BELL

> 달이 부서진 밤, 마지막 종은 울리지 않았다.

**한국어 중세 판타지 픽셀 시네마틱 RPG** · 브라우저 게임 · 모바일/PC 대응

## v1.2 패치 — 달빛이 이끄는 여정

- 이야기가 끝나면 캐릭터가 **지정된 경로로 자동 이동**합니다.
- 숲·폐허·성당에서 **정해진 전투 이벤트**가 시작됩니다. 자유 이동 중 적들이 몰려오는 방식이 아닙니다.
- 일반 공격은 **자동 검격**, 직접 누르는 버튼은 **달빛 파동 스킬 하나**입니다.
- 성장 시 **공격력 / 체력 / 마력** 중 원하는 능력을 직접 선택합니다.
- 선택에 따라 검의 빛, 망토 효과, 달빛 표식 등 **캐릭터 외형에 변화**가 생깁니다.
- 현재 **레벨·공격력·체력·경험치·다음 이야기·이동 상태**를 HUD로 보여줍니다.
- 세로 화면의 과도한 확대/왜곡을 줄이고 풍경 디테일, 달빛 길안내, 제목 화면 그림을 개선했습니다.
- 대화창 진행 버튼을 크게 만들고 창을 누르면 대사가 넘어갑니다.

## 플레이 방법

1. 아래 게임 주소로 접속해 **새로운 여정** 또는 **이어하기**를 선택합니다.
2. 대화를 넘기면 다음 장소로 **자동 이동**합니다.
3. 정해진 전투 장면에서 캐릭터가 **자동으로 공격**합니다. 필요할 때 우측 하단 **달빛 파동** 버튼을 누릅니다.
4. 레벨이 오르면 세 가지 축복 중 하나를 눌러 능력을 강화합니다.
5. 진행이 잠시 멈춘 것처럼 느껴지면 **길 안내 / 이동 계속**을 누릅니다.

게임: https://drink3412-byte.github.io/last-bell/

## 파일 구조

- `index.html` — 게임 UI 및 화면
- `game.js` — 픽셀월드, 전투, 대화, 고정 경로, 성장 및 저장
- `style.css` — 모바일/PC 디자인
- `title-art.svg` — 메인 화면 배경 아트
- `.nojekyll` — GitHub Pages 배포 지원

서버나 외부 JavaScript 라이브러리 없이 정적 웹 페이지로 실행됩니다. 진행 상태는 브라우저 저장소에 기록됩니다.

**저장 기록 안내:** 이전 버전(v1.1)의 탐험 상태는 순서형 진행에 맞춰 마을 시작 지점으로 정리되며, 보유 은화·레벨·장비 능력치는 유지됩니다.
